# UK spike, 15 Nov 2026

First full crawl of UK catalogues from the Dateno registry, run in GitHub Actions (commit d0131a9, 86 minutes, 33.6k requests).

| | |
|---|---|
| Catalogues harvested | 86 of 142 (18.9k records linking to services) |
| ArcGIS server roots reachable | 42 of 91 |
| Services crawled OK | 13.7k of 17.2k (80%) |
| Layers found | 60.2k (34k distinct by title and publisher) |
| Sampled layers returning data | 91% of 3.9k checked |
| Index size | 10.5 MB GeoParquet |

**Metadata.** Only 12% of layers carry their own description. Catalogue records add a further 32%, which is why harvesting catalogues first matters. 58% state some licence or constraints, but only 15% name a recognised open licence. 13% declare an ISO or INSPIRE theme.

**Quality bar.** At first, 60% passed. On review that was too generous:
- One service description shared across hundreds of layers counted as every layer's description.
- Code-like titles could still pass.
- The registry tags the European Environment Agency as "civil society".

With those fixed (a shared description only counts for services of three layers or fewer, a code-like title fails unless a catalogue record names the layer, and publisher overrides added), **21.2k layers pass (35%), about 11.7k distinct datasets**. A random sample of the passing set reads like a usable UK catalogue: ONS boundaries, the Crop Map of England, Natural England habitats, council tree preservation orders, brownfield registers.

**What's lost and why.**
- About half the unreachable ArcGIS roots are stale entries in the registry.
- 606 requests were refused by robots.txt.
- Some services need a token.
- Duplication is high: the same data is often published as both MapServer and FeatureServer, and again as WMS.
